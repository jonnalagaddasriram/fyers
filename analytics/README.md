# Tick Analytics

This is a standalone diagnostic tool to process and report on the `ticks.txt` JSON lines dump generated by the Fyers WebSocket trading client.

## Usage

This tool reads `ticks.txt` from the current working directory. You should run this utility from the **root** of your project (where `ticks.txt` is located).

```bash
# Run from the startup/algotrading/fyers directory
go run ./analytics/main.go
```

## Metrics Calculated
* **Total Records Processed**: The raw count of JSON tick lines cleanly parsed.
* **Volume Distribution**: A percentage breakdown of how many ticks belong to which symbol/instrument.
* **Average Latency**: The average time difference between the exchange's timestamp (`ExchTimestamp`) and the local machine's ingest timestamp (`RecvTimestamp`). 

*Note: The Fyers API provides the Exchange time at a 1-second precision boundary. Therefore, if your local clock differs, latency numbers can occasionally dip into negatives. We track them down to the millisecond scale regardless to help measure relative jitter.*
